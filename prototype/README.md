# FIXFLOW — 공간 관리 서비스 프로토타입

고객의 서비스 접수부터 견적 비교, 방문 일정, 작업 보고, 수금 확인, A/S까지 연결하는 로컬 체험 서비스입니다. 첫 화면은 서비스 안내와 접수 버튼을 중심으로 구성하고, 고객·협력업체 화면은 좌측 소개 이미지 없이 화면 너비에 맞춰 펼쳐집니다. 상단 공통 메뉴에서 FIXFLOW 홈·고객서비스·협력업체·운영 콘솔로 이동합니다.

## 실행

`index.html`을 열거나 이 폴더를 정적 HTTP 서버로 제공합니다. 별도 빌드는 필요하지 않습니다.

| 화면 | 경로 | 체험 계정 |
| --- | --- | --- |
| 서비스 첫 화면 | `#/` | 로그인 불필요 |
| 고객 | `#/c` | `010-1234-5678` → 화면에 표시된 인증번호 입력 |
| 협력업체 | `#/p` | `partner1` / `demo1234` (한빛설비), `partner2` / `demo1234` (맑은청소), `partner3` / `demo1234` (바른전기) |
| 운영 콘솔 | `#/a` | `admin` / `demo1234` |

다른 휴대폰 번호로 인증하면 가상 신규 고객으로 이용할 수 있습니다. 협력업체 가입 신청은 비밀번호와 분야·지역·증빙을 입력하고, 관리자 승인 후 활동하는 흐름입니다. 화면 아래의 **체험 도구**에서 장면 이동과 초기화를 할 수 있습니다.

## 기능

- 고객: 문자 인증 방식의 무가입 접수, 분야별 질문, 사진 또는 촬영 불가 사유, 최대 3개 최신 견적 비교·선택·취소, 추가 작업 승인·반려, 완료 확인·보완 요청, 지급 기록, 원작업에 연결한 A/S.
- 협력업체: 가입·승인 대기, 견적 유형과 자동 합계·수정 이력·수정본 재검토, 방문 일정, 전후 사진 전송·재시도, 추가 작업 요청·철회·재요청, 점검 항목과 완료 보고, 수령 기록.
- 운영 콘솔: 확인 필요 목록, 견적 요청·마감·공개, 전화 대리접수와 동의 근거, 추가 작업 이중 승인, 수금 대조·정정 이력, 협력업체 승인, 고객·사업장 조회, 엑셀 내보내기, 업무 처리 기준.
- 검증: 인증번호 3분 만료·5회 오류 제한·번호 변경 확인, 화면·계정 전환 시 비동기 결과 폐기, 금액·날짜 검증, 중요 처리 직전 권한·현재 상태 재확인, 확인창의 이전 상태 재사용 차단.
- 수금은 금액·거래 일시(분 단위)·방법·청구액을 대조합니다. 확인 근거를 적어도 차이가 남아 있으면 재확인 대상으로 유지합니다.

## 검증 기록 (2026-11-18)

- JavaScript 구문 검사와 Node 회귀 검사 **52건 통과**.
- Chrome에서 비로그인 접수, 인증 후 번호 변경 차단, 접수 저장, 관리자 메뉴 이동, 업체 견적 제출, 관리자 공개, 고객 선택·취소·재선택, 추가 작업 승인과 청구액 반영, 작업 시작·완료 보고·고객 완료 확인·음수 금액 차단·지급 기록 저장을 직접 확인.
- 협력업체 진행·완료 메뉴, 방문 일정 등록, 사진 전송 도중 화면 이동, 관리자 검색 직후 화면 이동을 확인.
- 데스크톱과 모바일 390px에서 화면·메뉴·가로 넘침을 확인. 검수 중 애플리케이션 콘솔 오류 없음.
- 추가 검수: 공개 견적의 수정본은 관리자 재검토 전까지 고객 선택을 막고, 재공개 후 최신 버전만 표시하는 흐름을 확인. 이전 버전의 금액·이력은 보존함.
- 추가 검수: 대리접수 고객 변경 시 동의·근거 초기화, 주소 누락·미래 동의 시각 차단, 개인 고객 목록 표시를 확인.
- A/S 배정 → 업체 처리 완료를 확인. A/S가 진행되더라도 수금 차이는 별도 상태와 진행 표시로 유지함.
- A/S 사진 처리 중 제출 차단, 오류 안내, 최대 6장 제한과 닫힌 창의 지연 결과 폐기를 검사함. 담당 업체 홈과 완료 메뉴에는 배정된 A/S의 처리 알림을 표시함.
- 실제 파일 선택은 Chrome 확장 프로그램의 파일 접근 설정으로 검수가 제한됨. 예시 사진 첨부와 파일 읽기 결과의 폐기·오류 처리는 별도로 검사함.

외부 패키지 없이 회귀 검사를 실행합니다.

```sh
node tests/regression.cjs
```

`tests/flow.cjs`와 `tests/smoke.cjs`는 Playwright를 별도로 설치한 개발 환경에서 사용할 수 있는 통합 흐름·화면 탐색 보조 스크립트입니다. 변경된 메뉴 선택자도 맞춰 두었으며, 이번에는 이 두 스크립트를 실행하지 않고 Chrome에서 실제 화면을 직접 검수했습니다.

## 체험 범위

데이터와 계정은 모두 가상이며 현재 브라우저에만 저장합니다. 실제 개인정보나 비밀번호를 입력하지 않는 체험용입니다. SMS, 외부 파일 서버, 실제 결제, 서버 인증·권한은 연결하지 않습니다. PWA 설치·오프라인 동작은 구현하지 않았으며 모바일 화면 형태를 확인할 수 있습니다. 진단형 견적의 최종 재확정·일정 경합 방지 등 고도화 흐름은 별도 구현 대상입니다.

사진은 긴 변 360px의 화면용 썸네일만 저장합니다. HEIC는 브라우저가 해석할 수 있는 경우에 지원하며 읽기 실패 시 안내합니다. 네트워크 실패 옵션은 로컬 사진 전송의 재시도 상황을 재현합니다. 엑셀 모듈을 불러오지 못하면 CSV로 내려받습니다.

서비스 이미지는 AI로 제작한 예시이며 실제 고객 현장이나 작업 증빙이 아닙니다. 상세 제작 기준은 `assets/images/README.md`에 있습니다.

디자인 보완: 공간 보수 카드와 이용 안내에 `assets/images/repair.jpg`를 추가했고, 기기 모형 테두리를 없애고 파란색·흰색 중심으로 작업 패널과 지표 카드를 정리했습니다.

반응형 화면 정리: 고객·협력업체의 좌측 소개 영역을 제거하고 화면 전환 메뉴를 상단으로 옮겼습니다. PC 1200px·모바일 390px에서 로그인·작업 목록과 고객 서비스·협력업체·운영 콘솔·홈 이동을 확인했습니다.

메뉴 UI 정리: 별도 제목 바와 하단 탭을 제거하고, 서비스 전환 버튼과 화면별 메뉴·뒤로가기·로그아웃을 상단에 모았습니다. 메인·고객 화면의 ‘내 접수 확인’ 표기는 ‘고객서비스’로 통일했습니다. PC·모바일 메뉴 이동과 가로 넘침을 확인했습니다.

공통 서비스 전환 버튼: 홈·고객서비스·협력업체·운영콘솔(로그인 포함)에 동일한 마크업을 사용합니다. PC에서 버튼 110×42px·간격 8px, 모바일 390px에서 버튼 약 108.66×42px·간격 8px로 모든 화면이 동일함을 DOM 실측으로 확인했습니다.

사용성 개선: 고객 홈을 간결한 인사·클릭 가능한 현황 카드와 작업 목록으로 구성했습니다. 내 접수에 접수번호·서비스·장소 검색, 전체·확인 필요·진행 중·완료 필터, 결과 없음 안내와 초기화를 추가했습니다. 협력업체 홈에도 클릭 가능한 현황 카드와 진행 작업 바로가기를 제공하며, 견적 응답 마감은 날짜·시간으로 표시합니다. PC 1200px·모바일 390px에서 검색·상태 조합·검색 초기화·비회원 인증 진입·인증 후 접수 조회·작업 이동을 확인했습니다. 공통 서비스 버튼은 110×42px·간격 8px를 유지합니다.

최종 재검수: 생성된 화면 HTML과 index.html 총 159개 스냅샷의 태그 중첩·중복 ID·label 연결·이미지 대체 텍스트를 검사했습니다(가상 데이터·DOM 모의 환경의 구조 검사). CSS 2개 파일의 문자열·주석을 제외한 괄호 구조, 모든 JS 구문과 로컬 자산 경로를 확인했습니다. 실제 Chrome에서는 PC·768px·390px·320px 화면, 접수 6단계와 인증, 견적 선택 확인창 취소, 협력업체 완료 메뉴, 관리자 주요 메뉴·견적·수금·이력 화면을 확인했습니다. 320px에서 협력업체 메뉴와 로그아웃이 겹치는 문제 및 관리자 상세 표의 오른쪽 열 잘림을 수정했습니다. 완료 대기·관리자 안내 문장을 다듬었고, 접수 단계 안내 20px와 기존 문자 인증 UI는 유지했습니다. 기존 회귀 검사 51건 통과, 검수 중 콘솔 오류 없음. 실제 파일 선택과 외부 SMS·서버 연동은 위 체험 범위의 제한을 따릅니다.

추가 최종 재검수: 320px에서 협력업체 수령 기록의 일시 입력창이 방법 선택창을 밀어내는 문제를 확인해 모바일에서는 금액·일시·방법을 한 열로 배치하고, 태블릿·PC에서는 폭이 충분한 두 열 배치를 유지했습니다. 관리자 확인 필요 목록의 주기적 갱신은 사이드 메뉴가 열린 동안 화면을 다시 그리지 않도록 보완했습니다. 가입 폼의 분야 선택 후 입력 유지, 관리자 로그인 전후, 메뉴 유지, 입력창 배치를 실제 Chrome에서 확인했습니다. 메뉴를 닫으면 자동 갱신이 재개되는 회귀 검사를 추가해 총 52건 통과했습니다. 생성 HTML 159개 구조 검사·CSS 구문·JS 구문·로컬 자산 경로 검사도 통과했습니다.
